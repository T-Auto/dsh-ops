# File-tool benchmark baseline — Windows x64, 2026-10-16

This is a repeatability baseline, not a performance fix. Baseline and candidate
are byte-identical release workers built from source commit
`6a7a4c79847705e7025b0467c03f005020efa263` (0.3.0). Native tree:
`09d7cdd9cbf4752a5e73ec0f382c5314052051d3`.

- Worker SHA-256: `863325cb0fddeaaf4986694d22986120dd28eb5c12c7f82c15fcbf251c42af27`.
- CPU: Intel Core i9-13980HX, 32 logical processors; Windows x64.
- Node: 24.19.0. Rust: 1.99.1 (`58cf8f9c3`, 2026-10-13).
- Build: `cargo build --release --locked --offline --manifest-path native/Cargo.toml --target-dir D:/dsh/dev/_test/issue-87/build`.
- The preserved worker and local build provenance are in the ignored
  `out/_test/file-bench/binaries/` directory. Binaries and generated fixtures
  are not committed.

Each query has one warmup per engine and five alternating paired rounds.
The watchdog is 60 seconds per worker. Medians exclude timeouts and native
rejections; rejection timings are saved separately in JSON. No speedup claim
is meaningful for identical binaries; variation reflects measurement noise.

The initial full-size run overlaps local verification during some early
queries. Its times are diagnostic only. The subsequent reduced-file-count
run is serial, after the gate and full-size run finish. It preserves all
large-file/long-line boundaries and directory depth; its times must not be
presented as full-size throughput. No caches were cleared and no Defender
configuration was changed.

The default full-size deep tree triggers the watchdog on this machine. Use an
explicit smaller `--scale` for quick local checks; retain the default 10k-file
fixture when measuring full-size traversal.

The 33 MiB hex inspection intentionally returns `OUTPUT_LIMIT`. A separate
accepted 8 MiB input measures small hex-window reads. The invalid UTF-8 suffix
is queried separately, so a preceding valid match cannot hide that case.

## Validation

- Benchmark self-tests: all six checks passed, including watchdog process exit,
  mismatch suppression, native error diagnostics, fixture ownership and CLI
  report exclusivity.
- Full local gate: manifest 58 checks and all 16 test suites passed. Gate ran
  with TEMP/TMP explicitly set to an isolated test directory, the real
  worker at standard source/package paths, and real locally built Bash IPC
  payloads. DSH_OPS_WORKER_BIN was unset: that override defeats the existing
  PTC isolated-package-resolution assertion.
- Fixture parent is empty after both completed runs. Test/report output is
  confined to explicitly named test directories.
- GitHub Actions remains disabled; this is local verification evidence.

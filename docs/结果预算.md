# 结果预算与会话生命周期

OPS 工作进程单次执行上限为 30 秒。同一宿主会话的 Native 与 PTC 共用先进先出的调用队列：
最多同时执行两次、等待八次。队列溢出返回 CALL_LIMIT，且无副作用。取消的等待调用不会启动；
获得执行资格后重新检查权限。Native 模型文本按转义后的字节计算，上限为 64 KiB；工作进程
传输收集上限另设为 128 KiB。规范数据缓存限额为每结果 10 MiB、每会话 100 MiB。三者分别计量。

引用缓存位置来自可信宿主元数据。Windows 使用真实沙箱提供者的会话临时目录及其专用写入能力。
PTC 仍通过宿主沙箱执行，Native 固定文件操作保持原有权限执行路径。完全访问模式准备缓存时
主动收窄为工作区写入权限。无法准备缓存时，文件操作继续返回有界且明确标注不完整的结果；
创建引用则报告缓存不可用。PTC 不会回退为无沙箱执行。

引用绑定当前活动会话、权限、凭据保护规则、操作根目录和生产工具。只接受当前可见且可执行的
生产工具及已获准执行的工具。权限模式变化会使原有绑定失效，包括收窄为只读。只读调用不会
创建缓存或更新 LRU。已有旧式审计引用保持独立的约定。

会话销毁立即使引用过期，取消等待及执行中的调用，等待执行结束，再按当前宿主权限清理经过
验证的快照和暂存文件。稳定锁及未知文件保留，审计数据不清理。只读模式或宿主服务不可用时，
物理清理可能无法完成并记录诊断；不安排自动重试，最多一个会话配额的残留文件需由宿主临时目录
清理或操作者删除。内存中的新会话随机标识保证重启后不能重新使用磁盘残留引用。
各组件共享生命周期；最后一个 Native/PTC 所有者卸载时清理剩余会话。清理为内部操作，模型
不能通过工具参数发起。

## Native 与 PTC 引用分页

文件组件独立提供 Native ops_result，只允许 page/release；不依赖 PTC 组件。同一个能力目录条目还提供
PTC 的 put/page/release。纯 PTC 作用域保留完整参数，Native 子作用域使用文件组件的分页投影。
关闭文件组件会撤回该投影，不影响独立 PTC 组件。高级工具发现后续负责按需发布；此能力不改变官方工具。

Native 仅接受 ref://，不接受旧审计 ID、put 或 purge。省略 root 时使用当前会话 cwd；cwd 改变后必须
传入原始 referenceRoot。PTC 默认使用工作区根目录。引用不授予权限：不同会话、根目录、权限变化或
生产工具不可见都拒绝读取。release 仅删除缓存观察结果，不删除业务文件。

默认 offset=0、limit=64、maxBytes=16384；范围分别为 1-512 行和 512-65536 字节。equals 先按顶层精确
值过滤，fields 再投影，偏移按过滤后的存储行计数。新引用默认 ttlMs=0（会话生命周期）；PTC put 可指定
最多七天。createdAt 使用 Unix 毫秒。整个 put 请求最多 2 MiB，单个物理快照最多 10 MiB。旧审计协议不变。

Native 只显示完整存储行，转义后的内容最多 64 KiB。仅在 displayComplete=true 时使用 nextOffset；否则
用较小 limit/maxBytes 或更少 fields 从同一偏移重试。pageComplete 仅表示存储行分页完成。source 保留
原操作事实、root、capturedItems 和 captureComplete；读完分页不能使未完成的扫描变为完成。
source.itemEncoding=tagged-json-v1 时，kind=item 行在 value 中携带数据；item-json-chunk 行包含 index、
chunk、byteOffset、text、complete。按同一 index 的 byteOffset 顺序拼接 text，收到最后一片后才进行
JSON.parse；单独的最后一片不是完整逻辑项。快照仅覆盖所请求的操作或页面，不表示无限制的整个查询。

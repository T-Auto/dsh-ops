# 路线图

English: [Roadmap](roadmap.md).

以下是方向，不是交付日期或承诺；优先级会随宿主版本和使用反馈调整。已发布变更见 [CHANGELOG](CHANGELOG.md)。

## 已发布

- 0.3.0：Windows x64 原生 Rust 文件工具与受约束的 PTC 批处理。
- 0.3.1：Windows x64、Linux x64 和 macOS Apple Silicon（darwin-arm64）跨平台支持。

## 0.4.0 候选

Native/PTC 独立投影、作用域发现、有界 CSV/TSV、DOCX 与受限 PDF 读取、运行时/设置变更和严格 TypeScript 源码已实现。本页不是发布公告：最终证据须满足已批准的 OPS 0.3.x BM-01 门槛与文件/发现 BM-03 预算，同时单列官方对照及含 Bash 的完整启动总数。范围和格式限制见[候选说明](0.4.0发布候选.md)。

- macOS Intel（darwin-x64）在 macOS 13+ 上的支持已实现、待审阅；macOS 12 的 `CLONE_ACL` 回退是独立后续项，见 [macOS](macos.zh.md)。

## 后续方向

- Windows ARM64、Linux ARM64 平台；macOS 12 的 `CLONE_ACL` 回退（Intel 与 arm64）在 macOS 13+ 支持落地后处理。
- 扩展 0.4.0 有界 DOCX/PDF 子集以外的文档支持。
- Web 搜索、HTML 转 Markdown、更多 PTC 工具与有界结果投影。
- 同步双语文档并补充故障排查；跟踪上游 DSH 接口变化。

提出使用场景请提交 issue；流程见[贡献指南](贡献指南.md)。

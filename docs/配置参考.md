# 配置参考

[English](configuration-reference.md) | 中文

OPS 沿用单行插件页：bundle 只插入一个 `dsh-ops` 行。内置预设和显式配置的自定义预设共用消费者装配流程；仅安装不会接管未知预设。插件作者也可独立挂载[公开集成接口](集成接口.md)。

## 单行开关

| 分区 | 默认与行为 |
| --- | --- |
| `global` | `bash`、`hidePwsh`、`hideOfficialTools`、`dynamicTools` 默认 true，门控该行管理的消费者对应选项 |
| `minimal` | 默认开启；无基础文件常驻面，可启用 Bash 和动态选择 |
| `standard`、`cordis` | 默认开启；Native 常驻读取/搜索/分页，可选 Bash、替换与发现 |
| `ptc` | 默认开启；真实宿主 PTC 展示下的类型化常驻 API 和渐进式 SDK |
| `presets` | 默认空；精确 preset id 到显式消费者选项的映射 |
| `discovery` | 默认开启；内置 Native 池、maxResults=3、无启动选择 |
| `panel`、`tui` | 默认关闭；采集与只读侧栏 |
| `other.pwsh7Link` | 未保存时跟随联动检测，已保存布尔值优先 |

页面使用原生 Switch。内置卡片默认收起；关闭卡片只置灰，不清除保存值。Standard/PTC/Cordis 提供默认开启的 `residentTools`，与动态加载独立；Minimal 保留不常驻的产品默认，若要改变可用 `presets.minimal` 显式选择。Bash 独立发布；文件替换和 Windows 宿主 PowerShell 隐藏也彼此独立。

总开关作与门控，不覆盖消费者保存意图。pwsh7 联动强制关闭该行管理消费者的 `hidePwsh`，让宿主 Shell 保持可见供 `dsh-win-pwsh7` 使用。这些是工具发布选项，不是文件系统授权，不会绕过宿主权限。

保存只写改动字段的精确嵌套路径，并带页面读到的 revision；冲突保留草稿，重置读取当前保存值。运行时状态区展示真实平台、受管理/Git Bash、PowerShell 与联动事实；安装/删除须先预览再明确执行，配置保存不部署二进制，也不改 PATH。

## 自定义消费者

```yaml
presets:
  acme-chat:
    enabled: true
    files: true
    residentTools: true
    residentNames: [read_files, stat]
    shell: false
    hidePwsh: false
    discovery: true
    allowedTools: [diff, grep]
    alwaysLoaded: [diff]
    replaceOfficial: false
    promptPolicy: true
    extraGuidance: Use bounded repository inspection.
    externalTools: [acme_lookup]
    externalAlwaysLoaded: []
    externalDisabled: []
```

映射键就是精确 preset id，内部不要重复写 `preset`。已配置项出现在同一个原生开关页，提供启用、文件、常驻、Shell、隐藏、发现、指导开关。宿主 descriptor 同时接受详细配置；名称列表与运行时路径可在 YAML 保存。带点的 id 是完整路径段，不会被拆成嵌套对象。

未列出的预设保持原样。显式配置内置 id 时，两种挂载顺序都会覆盖内置默认。`enabled: false` 保留显式禁用绑定，不回退到内置工具面；作用域诊断仍可访问。

| 选项 | 默认与含义 |
| --- | --- |
| `profile` | 默认 native，快捷档为 native/ptc/discovery/shell |
| `files` | native/PTC 为 true，discovery/shell 为 false；控制内置文件常驻面 |
| `residentTools` | true；关闭基础常驻，不抹去显式发现选择 |
| `residentNames` | Native 原始名称列表，默认 inspect_local_file/glob/grep/read_files/result；可以为空 |
| `shell` | 除 shell profile 外默认 false；宿主授权的常驻 Bash，不属于发现池 |
| `hidePwsh` | 默认 replaceOfficial && shell；独立控制 Windows 宿主 Shell 隐藏 |
| `presentation` | 除 PTC profile 外默认 native；只选投影，不改变宿主展示 |
| `discovery` | 除 shell profile 外默认 true；关闭选择入口/SDK loader，但保留显式启动选择 |
| `allowedTools` | 发现开启时默认所有可加载能力，否则空 |
| `alwaysLoaded` | 空，必须在允许列表内；与 Native 常驻集合独立 |
| `replaceOfficial` | false；只隐藏实际就绪的、经过核对的原版文件对应工具 |
| `promptPolicy` | true；指导只广告实际发布的工具 |
| `extraGuidance` | 空，Native 专属；PTC 明确拒绝 |
| `externalTools`/`externalAlwaysLoaded`/`externalDisabled` | 默认空，外部允许/启动/禁用名单，禁用优先 |
| `binaryPath`/`bashPath` | 默认受管理解析，可显式指定 |
| `required` | false；所需 worker 缺失时拒绝激活 |
| `denyCredentialReads` | true，Native 可显式覆盖；PTC 拒绝覆盖并持续执行边界 |
| `downloadGuard.template` | 空；未设置时完全不生效。一条含 `{url}`（必需）与可选 `{file}` 的命令模板，会落盘的 shell 下载将被重定向到它 |
| `allowSystemShellFallback` | false，Windows 自动系统回退须主动选择 |

`shell: false` 保留显式 `bashPath`、`allowSystemShellFallback` 与 `hidePwsh` 意图，但不发布 Bash、不隐藏宿主 Shell；重新启用时应用保存值。自定义 PTC 卡片锁定 `files` 开启，并提示用 `residentTools` 控制启动 API。PTC 必须 `files: true`，且宿主真实为 run_code-only 展示并有 PTC runtime；不接受 `residentNames`，不把外部 Native 提供者当类型化 SDK。[第三方 PTC 注册暂不支持](外部工具提供者.md)。

独立 `integration({ preset, ...options })` 使用同样选项和装配器，但归其挂载插件所有，不由无关 bundle 总开关控制。同 id/同 scope 不重复绑定；见[作用域与生命周期边界](集成接口.md#生命周期与归属)。

## 内置高级配置

内置分区保留 worker/Shell 配置：`binaryPath`、`required`、`bashPath`、`denyCredentialReads`、`promptPolicy`、`extraGuidance`、`allowSystemShellFallback`，以及 `publishBashTool` 作为 bash 的历史别名。`ptc.allowedTools`/`ptc.alwaysLoaded` 控制类型化 SDK；`discovery.allowedTools`/`discovery.alwaysLoaded` 控制内置 Native 池。全面客制化使用 `presets.<id>`，不要继续在核心添加 preset 名称特判。

`discovery.enabled` 只控制内置 Native 发现入口，不控制 PTC SDK loader；后者由 `ptc.dynamicTools` 与 `global.dynamicTools` 控制。Native 配置其余键为 maxResults（1–5，默认3）、allowedTools、alwaysLoaded、binaryPath、required、denyCredentialReads。启动名单必须被允许；动态入口还须预设与全局动态开关同时开启。Native 与 PTC 的选择均不执行工具动作，下一模型步骤才激活。

## 凭据与执行边界

凭据围栏覆盖所有方向：拒绝的路径不能作为读取源、写入或 copy/move 目标，也不能被删除。历史名 `denyCredentialReads` 因而不只保护读取；danger-full-access 也默认开启。拒绝为 CREDENTIAL_DENIED、无效果、不可重试，不泄露路径或父目录。DSH_OPS_DENY_READ 可扩大围栏。Native 显式关闭是操作者配置，不是额外授权。

Windows 受限 Bash 必须使用固定 MSYS 和经校验的私有 IPC 代理；不兼容的自定义 Bash 报 EXECUTOR_UNAVAILABLE，不得绕过约束或换 Shell 修复。POSIX 使用宿主 Bash 与宿主沙箱。显式 worker/Shell 路径失败时不偷偷换执行器。PowerShell 安装是独立宿主操作，OPS 不捆绑或覆盖宿主 PowerShell。

## 采集与侧栏

`panel.enabled` 控制采集；启用内部 capture 默认 true，旧显式 false 仍关闭。textLimit 为64–100000（默认2000），maxSessionBytes 为65536–268435456（默认8388608）。只写会话工作区 `.dsh-ops/panel/`，不写真实 DSH home。报告可能包含对话和工具正文，须 Git 忽略。停止会取消排队 I/O、等待已发工作，保留可恢复 NDJSON，不自动做最后折叠。tui 仅接受 maxSessions/maxActive/recentLimit，不授予执行能力；见[侧栏](tui-panel.zh.md)。

## 迁移

bundle 不再插入 mode-*、discovery、compat、panel、tui、shell、file、ptc、hide-official 或 background 独立行。迁移值到单行后删除旧覆盖，OPS 不自动重写 profile。保留的 legacy 组件在 merged bundle 下告警并保持惰性。`dsh-ops/compat` 已随旧兼容开关移除；用 hideOfficialTools/replaceOfficial=false 和 hidePwsh=false 保留原版工具。

旧 FastCtx 键只做保存配置迁移的类型校验，不启用旧执行器。configUpdateVersion 是迁移标记，不是能力开关；shellPolicy、deniedHostTools、replaceTools 及旧隐藏字段不属于当前消费者。

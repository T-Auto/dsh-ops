# 搜索覆盖范围与续页

Native 渲染会在匹配文本之前显示扫描覆盖范围与恢复建议；公开参数声明 `continuation`，结构化输出声明完整报告字段。

English: [search-coverage.md](search-coverage.md).

开发计时与等量工作对比见[搜索性能诊断](搜索性能诊断.md)。

`glob` 和 `grep` 在原有条目之外返回 `SearchExecutionReport`。旧版信封中的
`status: completed` 只表示工作进程已返回结果；判断结果是否完整时，仍须检查
`scanComplete`、`pageComplete` 和 `complete`。

| 字段 | 含义 |
| --- | --- |
| `scanComplete` | 所有查询范围内的候选项均已观察，且没有读取、编码、大小缺口或执行早停。 |
| `pageComplete` | 本次请求页中的已观察条目均已完整输出，与是否还有后续页相互独立。 |
| `scannedFiles` | 已检查且权限允许、非隐藏的普通文件候选数，包括被显式 glob 条件排除的文件。 |
| `skippedFiles` | 已知被排除或无法读取的普通文件数，不估算被跳过目录内部的文件数。 |
| `skipReasons` | 排除的文件/目录项或观察缺口的分类计数；跳过一个目录只计一次。 |
| `matchedObserved` | 当前已观察的匹配数：glob 为文件数，grep 为匹配行/跨度数。 |
| `matchedTotal` | 仅在 `scanComplete` 为 true 时出现，表示完整扫描的精确匹配总数。 |
| `truncatedBy` | `scan-budget`、`time`、`output-budget`、`row-limit` 或 `none`；非预算类读取/编码缺口可以为 `none`。 |
| `continuation` | 仅用于完整观察且状态未变查询的下一页不透明游标。 |

`grep` 的 count/files 模式按匹配文件分页，但 `matchedTotal` 仍表示匹配数；旧字段
`total` 表示页条目总数。扫描不完整时，不返回 `total` 和 `omitted`。原有 `matched`、
`matches` 和 `files` 均为已观察计数，不能替代覆盖标记。显式 `limit` 可以同时产生
`scanComplete: true`、`pageComplete: true`、`truncatedBy: row-limit` 和续页游标。
旧字段 `complete` 仅在完整扫描的最后一页也完整展示时为 true。

显式模式排除、隐藏路径、依赖/构建目录、凭据位置和禁止跟随的链接均不属于查询范围；
这些跳过计数不会单独使完整查询变为不完整。无法读取的目录项/目录/文件、非法路径编码、
超过 32 MiB 的文件及非 UTF-8 内容属于覆盖缺口：`scanComplete` 为 false，不返回总数或
游标，并通过 `nextAction` 建议缩小查询或修复缺口。报告不会泄露凭据路径或内容。

每次搜索最多检查 10,000 个普通文件、100,000 个目录项、128 层目录，累计读取 256 MiB。
协作式截止时间为 30 秒，在目录项、64 KiB 读取块及匹配之间检查；宿主取消机制和进程级
截止时间仍然有效。目录排序和 glob 候选表有界；grep 每次处理一个有界文件，只构造请求页。
后续共享预算工作将集中管理这些限制。

超过 128 层时只跳过该子树并记录 `skipReasons`，后续兄弟目录仍可扫描；目录项或文件预算耗尽
也会记录原因。这些缺口都使 `scanComplete` 保持 false。

续页时保留相同查询选项并传入 `continuation`，省略 `offset`，或传入游标给出的
`nextOffset`。游标绑定工具、宿主解析后的路径参数、会话、当前权限字段、工作区身份和观察
到的搜索状态。候选顺序确定；按修改时间排序时，同时间项保持该顺序。grep 指纹包含文件
内容，因此还原大小和时间戳无法隐藏字节变更；glob 指纹绑定观察到的路径和元数据。
查询、权限、游标校验值或观察状态变化会返回无副作用的 `SEARCH_STALE`，须丢弃游标并重新
查询。每次调用仍执行宿主权限及 no-follow 检查；游标和校验值都不授予权限。

当前实现通过重新扫描有界查询并校验指纹来续页，不冻结文件系统快照，也不支持越过扫描、
时间或覆盖缺口继续扫描。不完整遍历明确建议缩小查询且不提供游标。保存快照及通过结果
引用续取属于后续结果引用切片。

过大的匹配行可以返回带有 `truncatedInLine`、`bytesTotal` 和 `bytesOmitted` 的有界前缀，
此时 `pageComplete` 为 false。不会提供跳过缺失后缀的游标；`nextOffset` 停留在未完整条目，
并建议使用文本/十六进制范围读取该文件。完整扫描后被整行省略的条目可以正常续页。
输出按序列化 JSON 字节限制，而非字符数；搜索不创建审计或引用存储。

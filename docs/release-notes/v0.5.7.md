<h2 id="cn-v057">0.5.7 补丁版本</h2>

本版汇总自 `v0.5.6` 以来的修复，重点支持 DSH `0.2.3-alpha.2`，并保留原有 DSH `0.2.2` 兼容范围。

### 宿主兼容

- 支持范围为 DSH `>=0.2.2-rc.1 <0.2.3-0 || 0.2.3-alpha.2`、Cordis `~4.1.0 || 4.2.0-alpha.1`；不代表支持其他 DSH alpha 版本。插件 Node 范围仍为 `^22.19 || >=24`；使用 DSH alpha.2 时须满足宿主更严格的 `^24.22.3 || >=26.13.1` 要求。单独保留 Node 22 与 alpha.2 Node 24 的 CI 验证通道。（#1065）
- 优先通过 Cordis root symbol 解析宿主根上下文，保留 Cordis 4.1 回退，修复新宿主下插件激活失败的问题。（#1047、#1065）
- PTC 教学和示例适配 scoped Node REPL 的 `inspect(...)` 输出约定；仅在宿主明确声明时推断 console 输出，并更新工作目录、结果生命周期和会话模式切换的集成。（#1065）

### 问题修复与体验优化

- 面板记录 PTC 派发、作业生命周期、收件箱改写和待办写入，保留 Bash 作业的宿主调用身份及满视图中的替换结果。（#698、#909）
- 面板折叠与会话关闭重叠时保留封存报告；并发折叠共享更新，无效工作区减少重复告警，实时折叠从同一份字节生成内容和哈希。（#976）
- 按 agent 隔离工具注册与清理，保留原始失败原因，并在工具服务重启后恢复 Bash 和官方工具替换。（#953）
- 展示探测传递 agent 与所选模型，使 Native/PTC 检测中的人设变量正常解析。（#954）
- 执行器与其他设置共用带修订检查的草稿，界面切换语言后重新翻译保存提示。（#1028）
- 插件管理服务就绪后刷新 Windows 伴侣插件检测，只有成功查询确认未安装时才显示安装入口；Windows 测试夹具支持 Entra 用户 SID。（#750、#1031）

### 发行与安装

GitHub Release 提供含编译插件与 Windows x64、Linux x64、macOS arm64/x64 runtime 的安装包及 `SHA256SUMS`。Linux arm64 和 Windows arm64 不在支持范围内。发布工作流不会自动发布 npm；请使用本版 GitHub Release 安装包，不要把 npm 的旧版本视为已包含这些修复。

<h2 id="en-v057">0.5.7 Patch Release</h2>

This release collects fixes since `v0.5.6`, adds DSH `0.2.3-alpha.2` support, and retains the existing DSH `0.2.2` compatibility range.

### Host Compatibility

- Supported ranges: DSH `>=0.2.2-rc.1 <0.2.3-0 || 0.2.3-alpha.2` and Cordis `~4.1.0 || 4.2.0-alpha.1`; this does not admit other DSH alpha releases. The plugin retains Node `^22.19 || >=24`, but DSH alpha.2 requires the stricter host range `^24.22.3 || >=26.13.1`. Separate CI lanes cover Node 22 and alpha.2 on Node 24. (#1065)
- Resolve the host root through the Cordis root symbol first, with a Cordis 4.1 fallback, fixing activation failures on the new host. (#1047, #1065)
- Adapt PTC lessons and examples to scoped Node REPL `inspect(...)` output; infer console output only when explicitly advertised by the host. Update working-directory, result lifecycle and session mode-change integration. (#1065)

### Fixes and Improvements

- Capture PTC dispatches, job lifecycle, inbox splices and todo writes in the panel, preserving Bash host call identities and replacement results in a full view. (#698, #909)
- Preserve sealed reports when panel folds overlap session close; share concurrent viewer updates, reduce repeated invalid-workspace warnings, and hash the bytes actually parsed. (#976)
- Isolate registration and cleanup per agent, preserve original failures, and restore Bash and official-tool replacements after tools-service restarts. (#953)
- Pass the agent and selected model into presentation probes so persona variables resolve during Native/PTC detection. (#954)
- Share one revision-checked draft across executor and other settings, and retranslate save notices after language changes. (#1028)
- Refresh Windows companion detection when the plugin manager mounts, showing installation only after a successful inventory confirms absence; support Entra user SIDs in Windows test fixtures. (#750, #1031)

### Distribution and Installation

The GitHub Release provides an installable archive with the compiled plugin and Windows x64, Linux x64, macOS arm64/x64 runtimes, plus `SHA256SUMS`. Linux arm64 and Windows arm64 remain unsupported. The workflow does not publish npm automatically; use this GitHub Release archive rather than assuming an older npm version contains these fixes.

`0.5.5` 补丁版本，汇总了自 `v0.5.4` 以来的主要变更。本次为设置项逻辑更正后的重新发布构建，发布资产以本次上传的 `SHA256SUMS` 为准。

<h3 id="cn-v0.5.5">问题修复</h3>

- 修复强制默认预设会覆盖手动选择的问题：移除 `global.forceDefaultOpsPtc` 开关，改为行详情页的一次性按钮写入默认预设；apply、重挂载与卸载都不再改写默认，旧 profile 保存的该键仍可加载但不再生效。 @T-Auto
- 修复 PTC 在关闭常驻工具与动态加载时仍注册 `allowedTools` 候选池的问题：没有 loader 的作用域不再声明这些 API，首轮提示词不再多出约 22.5k tokens，常驻与默认加载行为不变。 @T-Auto
- 修复 Native 搜索诊断丢失并统一模式契约（#867）。 @Haoming9527

The `0.5.5` patch release summarizes the main changes since `v0.5.4`. This is the re-published build with the settings correction; the uploaded `SHA256SUMS` describes the current assets.

<h3 id="en-v0.5.5">Bug Fixes</h3>

- Fix the forced default preset overriding a manual choice: the `global.forceDefaultOpsPtc` switch is gone and one button on the row's detail page writes the default once; apply, remount and unload no longer touch it, while a saved key still loads with no effect. by @T-Auto
- Fix a PTC scope with resident tools and dynamic loading off still registering the `allowedTools` pool; a loader-less scope now declares none of those APIs, removing roughly 22.5k tokens from the first prompt while resident and default behavior stay unchanged. by @T-Auto
- Preserve Native search diagnostics and align mode contracts (#867). by @Haoming9527

# OPS 集成诊断

[English](diagnostics.md) | 中文

`dsh-ops/integration` 会在对应作用域发布只读的 `ops_status` 诊断工具。它报告当前预设、
可见工具、接入状态、外部提供者状态和可操作错误码；不执行文件/Shell/第三方动作，也不会
激活发现能力。

状态含义：

- `not-selected`：当前 Agent 没有显式 OPS 接入，也没有启用的内置模式。
- `ready`：接入已挂载，声明的宿主与运行时检查通过。
- `degraded`：已选择接入，但宿主服务、运行时、Shell、展示模式或发布不完整；不等于用户未选择。
- 外部 `available`：已允许且提供者存活，但按需加载；`pending`：将在下一模型步骤生效；
  `active`：已在当前作用域可见；`disabled` 与 `unavailable` 表示明确原因。

`PRESENTATION_MISMATCH` 必须检查实际 assemble 结果：PTC 要求 `run_code` 和非空
`tools:ptc-only` 段，不能用预设名或提示词建议推断。`PUBLICATION_UNAVAILABLE` 应先检查
接入生命周期、作用域和注册错误，再考虑权限。若官方工具已隐藏但对应 OPS 工具不可见，
这是替换控制器缺陷，不能要求用户重试。

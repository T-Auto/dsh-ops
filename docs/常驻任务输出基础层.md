# 原生任务输出基础层

[English](resident-task-capture.md)

此 #872 切片为 Windows 所属进程范围增加实时有界输出视图，以及基于持有进程句柄的根进程退出观测。
它不发布任务工具、不替换 fresh 执行、不实现宿主 jobs 适配器，也不在已知不兼容的 stock Niubash 上启用持久 shell。

`Range::spawn_with_retention(launch, Retention::Tail)` 为 fresh/task 读取者保留最新字节；
现有 `Range::spawn` 和 shell 私有通道仍保留有界前缀。两者共用原始 `Capture` 缓冲实现。
每个流上限为 1–128 KiB；仓库任务 fixture 默认沿用 fresh 的 64,000 字节内存上限，测试可指定更小上限。
达到保留上限后仍持续排空全部字节，并累计实际观测总量。

`Range::output_views()` 提供互不消费数据的独立视图。快照在同一把锁内读取保留字节、
它们在完整流中的起始偏移、观测总量、截断、EOF 和读取错误。
`read_from(offset)` 返回仍可用的后缀，并将 `next_offset` 推进到观测总量。
丢失状态相对于该读取者请求的偏移，因此已处于保留尾部窗口内的读取者不会继承其他读取者此前的丢失。
前缀模式会报告保留前缀之后缺失的字节。偏移按原始字节计数，包括 UTF-8 单元内部；文本解码属于投影层。
超出观测总量的游标被拒绝。实时空输出不是 EOF；读取失败保留已有字节和错误，不声明 EOF。
克隆视图仅持有输出存储，不延长进程或 Job 的所有权。

继承的 stdin 是写端已经关闭的管道，保持现有 fresh 宿主执行约定，且不改写 argv。
启动仍使用宿主约束后返回的精确 executable/argv、完整环境、显式句柄列表，
并在首条指令执行前原子加入嵌套 Job。

`root_exit()` 轮询保留的进程句柄。已触发退出信号的句柄可返回任何真实退出码，包括 259；
不单凭 `STILL_ACTIVE` 的数值判断存活。`wait_root_exit(deadline)` 对同一进程身份提供有界等待。
Windows 可能先报告 Job 活跃计数为零，然后根进程句柄才触发退出信号，因此不能以 Job 为空替代根进程退出。
反过来，根进程退出也不意味着后代或输出写端已经关闭。
任务完成必须同时满足所属范围回收已确认、根进程退出已观测，以及输出读取线程全部 join。
单个流的 EOF 也不证明进程执行完成。

仓库专用 `task_capture` owner 验证两种显式选择的生命周期。
普通 fresh 根进程退出后允许有界排空宽限，然后回收仍在运行的后代。
显式注册为后台任务的执行则保留所属后代，直到后代结束或任务/owner 关闭。
该 fixture 不是生产调度器，也不是自动提升后台任务的规则。
取消会对仍存活的根进程尝试所属控制台信号，再终止并 join 该任务范围。
控制 EOF 关闭所有任务；定向取消后同级任务仍可使用。

Windows 公开宿主探针断言 10 项：三种约束模式、stdin EOF、退出码 259、独立实时游标与真实终态 EOF、
两个 1 MiB 流仅保留各 64 字节、fresh 后代回收、显式后台后代生命周期、定向取消和 owner EOF。
它在紧急兜底清理前检查观测到的 PID 全部消失。
单元测试另外覆盖 UTF-8 原始字节偏移、前缀丢失、部分输出后的读取失败、Windows 实际管道句柄类型，
以及前序读取线程错误或 panic 后仍 join 后续线程。

```console
cargo test --locked --manifest-path native/Cargo.toml -p ops-process
cargo build --locked --manifest-path native/Cargo.toml --example task_capture
node bench/probes/probe-872-task-capture.mjs native/target/debug/examples/task_capture.exe
```

可恢复 spill、有界原生任务调度与通信、精确 Jobs 启动交接、已结束 spill 的保留策略仍是后续工作。
现有原始输出 spill 约定是 64 MiB 完整流文件及共用的 settled-spill ledger；此内存有界切片不声称已达到该能力。
结构化 PTC 结果引用不能替代原始输出存储。POSIX 进程范围仍显式不支持，
因为公开宿主的 fallback 尚不能为新建进程组建立所需所有权。

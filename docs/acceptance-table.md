## 五、不予验收的情形（出现任一，直接判不通过）

1. 硬门任一项不过，或证据缺失（只写"通过"但没有命令与输出）。
2. 修改测试断言、跳过测试、或改配置来"让它过"。
3. 受限模式下出现"沙箱不可用但仍执行"的路径。
4. 凭据内容出现在任何工具返回体或日志里。
5. 发布包缺少 `runtime/win32-x64/dsh-ops-worker.exe` 或 `bash-ipc` 产物。
6. 失败被记录为"环境问题"却没有任何证据（报错原文、退出码、复现步骤）。

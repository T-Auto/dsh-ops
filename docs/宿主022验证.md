# DSH 0.2.2-alpha.2 验证（#482）

English: [DSH 0.2.2-alpha.2 validation](host-022-validation.md).

**调查草稿；该宿主仍不在 `engines.dsh` 和 DSH peer 范围内。** adapter 能编译、工具能直接
执行，不足以证明模型请求兼容。DSH 0.2.2-alpha.2 要求 Node **24.9.0 或更高版本**；插件
原有 Node 22.19 下限仍适用于较早的受支持宿主。

该移植保留 #486、#487 的贡献，依赖 #542 的发布修复。测试使用已发布的 Native/PTC executor
包和新的批量执行 API；产品代码不替换宿主注册表或 executor。常规锁文件仍使用 0.2.1-rc.5。

## 复现

使用可丢弃 checkout 和独立依赖目录。`test/fixtures/host022/package.json` 记录本次使用的
已发布宿主依赖图，在该目录执行 `npm install --ignore-scripts`。仅把临时 checkout 的
`node_modules` 指向独立目录（Windows junction 或 POSIX 符号链接），保留正常 checkout
和依赖。执行 `npm run build:ptc` 构建匹配 worker，随后：

```console
npm run build
npm run typecheck
node test/run.mjs host-executor consumer-assembly preset-integration ptc-directory settings-ui host-metadata
node test/run.mjs progressive-loop credential-denial
node test/run.mjs ptc-sdk
```

第一组验证真实作用域 Native 文件调用、Node PTC 调用、PTC 直接调用拒绝、旧回调撤销、
executor 卸载、元数据、设置和 provider 组合。元数据检查会明确**拒绝** alpha.2。
alpha.2 的 executor 卸载会让该作用域不可用，直到显式安装替代者，不会继承祖先 executor。

真实 AgentLoop 组在 alpha.2 下失败：第一个 Native provider 请求缺少 `ops_discover_tools`
或配置的启动 `ops_stat`；第二个 PTC 请求缺少已选择的 `ops_stat` 声明。测试由真实宿主循环
驱动确定性的模型响应夹具，不访问模型或网络。PTC SDK 切换测试还捕获首份快照过期：切回
Native 后，实时注册表已经是 Native 工具，第一次装配仍包含 `ops_load_sdk`，第二次独立
装配才读到当前清单。

## 需要的准入契约

已发布 alpha.2 的 [`dsh-agent-loop`](https://unpkg.com/@deepseek-ai/dsh-agent-loop@0.2.2-alpha.2/lib/index.js)
先解析 `toolSet`，再装配提示词，之后才运行 `agent/pre-step`。
[`dsh-system-prompt`](https://unpkg.com/@deepseek-ai/dsh-system-prompt@0.2.2-alpha.2/lib/index.js)
在文本 waterfall 前收集工具 schema，并在 waterfall 后重新附上原数组。OPS waterfall 返回
新的装配不能更新原工具快照。拒绝 `agent/pre-step` 会消耗已领取的用户消息，不能当安全重试。

建议上游提供 **`tools.resolve()` 和提示词收集前可等待的作用域准备 hook**，或有界的准入
重启机制：释放旧 ToolSet、等待发布、重新收集 schema 与 SDK 文本，同时不消耗待处理用户
消息、不发出模型请求。验收应覆盖上述 Native 启动和 PTC 第二次请求断言，并保持权限撤销
和取消语义。

仅增加注册时 `when` 条件无法补入之后发现的工具，因为 `tools.resolve()` 在计算条件前
已经捕获注册表视图。改成稳定的预注册能力，需要一起处理 Native/PTC 定义、作用域所有权
和增量加载器生命周期；这属于独立设计改动，不能用放宽版本号代替。

alpha.2 也移除了旧 `modeFor` 预检。兼容测试保留保守的完整展示探针回退，不声称新宿主具有
旧宿主的 Native 预检开销或 Desktop 启动耗时。
